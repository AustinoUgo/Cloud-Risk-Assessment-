# Cloud-Risk-Assessment-
Fictional cloud risk assessment for a 200-bed Lagos hospital moving to AWS. Risk register, control gap analysis and 30/60/90-day remediation roadmap, mapped to CSA CCM v4, ISO 27001:2022 and NDPA 2023.
This project is a Cloud Risk Assessment for SecureHealth, a fictional 200-bed private hospital in Lagos migrating patient records to AWS. It identifies 20 risks (4 High, 16 Medium), maps them to CSA CCM v4, ISO/IEC 27001:2022 and the Nigeria Data Protection Act 2023, and sets out a 30/60/90-day remediation roadmap.
Example findings: R-001 (score 20) covers public S3 exposure of patient data, addressed through Block Public Access and AWS Config monitoring. R-002 (score 20) covers missing MFA on the root account and most IAM users, addressed through root MFA and IAM Identity Center.
The repository includes the risk register workbook, and the full report is linked below. All organisational details, findings and scores are fictional and illustrative.
